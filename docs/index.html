01 · Intervals & phrasing spread

Rewording a buyer question moves brand overlap far more than re-asking one prompt (arXiv:2605.27440). Hearsay pools multi-phrasing intents, publishes Wilson 95% intervals, and flags samples under n=5.

02 · Unblended real surfaces

OpenAI Responses search, Claude web search, Gemini grounding, and authenticated Codex or Claude Code CLIs stay in separate series. Missing or timed-out searches never enter denominators as brand absences.

03 · Citation gaps to controlled leads

Search queries, retrieved URLs, and final-answer citations are stored in separate layers so you can ship targeted page fixes and review lead deltas against an unchanged comparison page.

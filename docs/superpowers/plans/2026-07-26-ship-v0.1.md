> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Take feature-complete main (204/204) to a taggable, presentable v0.1.0: final METHODOLOGY/README/SECURITY/CONTRIBUTING, screenshots, the §19.5 acceptance gate, and the launch checklist — per master plan §16/§18/§19.5 and SPEC §9.

**Architecture:** No feature code. This plan writes documents governed by binding copy rules, implements the one remaining dev-only script (`scripts/screenshot.js`), and runs gates. Copy tasks include the binding claims verbatim; where prose is the deliverable, the task gives the section contract and the grep-gates that reject rule violations.

**Tech Stack:** Node 24 at `~/.local/node-lts/bin/node` (system node is v18 — use the full path for every command). Playwright via `npx playwright` for screenshots only — dev tooling, **never** a package.json dependency.

## Global Constraints (binding copy rules — §19.6, §20.1)

- **Never** cite star counts or claim "only/largest OSS" anywhere (§19.6 #11).
- **Never** print a flat dollar figure — cost is shown via the calculator screenshot + one sentence pointing at it (§19.6 #13, §4.3).
- **Never** pitch as "open-source alternative to Profound/Peec/Otterly" (§1.1 positioning rule). The pitch: *a measurement methodology you can run anywhere, that your agent can use.*
- Market claims only from the §20.1 evidence table, phrased exactly as listed there; retired claims (§20.1 bottom) must not appear.
- The §1.5 refusals are features — state them proudly, don't soften them.
- No real brand names in any screenshot or example (demo universe only: Notewell, Jotta, EchoPad, Quillo).
- No API key material anywhere, including screenshots of /settings (masked keys only).
- Zero npm dependencies stays absolute; `npx playwright` runs from the runner cache, `package.json` untouched.
- Every doc change ends with `~/.local/node-lts/bin/node --test` + `npm run typecheck` still green (the /methodology page renders METHODOLOGY.md — a malformed doc can break a page test).

### Task 2: METHODOLOGY.md — the credibility document

**Files:** Rewrite `METHODOLOGY.md` (currently a 15-line stub). Verify: `GET /methodology` renders it.

Write these sections, in order. Each gets plain-language prose (marketer-readable, no formulas beyond the one interval); the **bold claims are binding and verbatim**:

- [ ] **Step 1: Draft the sections:**
1. **What Hearsay measures** — repeated sampling of AI answers; every number traceable to stored answers ("receipts over scores").
2. **Sampling and confidence intervals** — why one answer is an anecdote; Wilson 95% CI in one sentence ("the error bar others hide"); every rate ships with n; n<5 flagged low-sample.
3. **Phrasing variance vs rerun variance (why intents exist)** — **"cross-paraphrase agreement (0.135–0.288) is far lower than same-prompt rerun agreement (0.50–0.61)"**, cite arXiv:2605.27440; Hearsay reports both spreads and never hides the phrasing number.
4. **What the API can and cannot tell you** — no memory, no personalization, no consumer-app system prompts; **"a logged-out discovery baseline, directional only"**; the planned paired API-vs-UI study, linked when published (§18).
5. **Deliberate choices** — no system prompt, provider-default temperature (closest to a default user); days without runs are gaps, not zeros; branded prompts excluded from share-of-voice denominators (they measure navigational recall, not discovery).
6. **Channel-size honesty** — **"organic LLM traffic is under 0.2% of visits for most sites (organicllm.org); complex, considered-purchase categories run multiples higher"** — and that's why Hearsay's cost structure is API-spend, not a subscription.
7. **What we refuse to fake** — the §1.5 list: no blended score, no rank positions, no prompt-volume estimates, no content generation — each with its one-line reason.
- [ ] **Step 2: Gates:** `rg -in "star|github.com/[a-z]" METHODOLOGY.md` → no competitor repos or star talk; `rg -n '\$[0-9]' METHODOLOGY.md` → no dollar figures; suite green (methodology page renders).
- [ ] **Step 3: Commit** — `git commit -m "docs: METHODOLOGY — sampling, variance split, caveats, refusals" -- METHODOLOGY.md`
